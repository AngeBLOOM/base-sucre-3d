# Base Aérea Escuela Mariscal Sucre · 3D

Escena de Blender 5.2 (EEVEE) de la SVBS para videojuego. Todo se genera con los scripts de `scripts/` (`reconstruir.ps1` arma la escena completa).

## Renders listos

| Carpeta | Qué hay |
|---|---|
| `renders/cliente/` | Recorrido completo de la base en 2K (44 vistas + mapa del camino) |
| `renders/hoy_2026-11-05/` | Entrada por dentro, plaza de la isla, comedor, CAA, DIDA con ventanas corregidas (2K) |
| `renders/entrada_2026-11-07/` | Entrada con avión, monumento 27N, pasos con garitas, paredón (2K) |
| `renders/entrada_final/` | Últimos borradores de la entrada: Tucano sobre el monolito, franja de tierra con árboles, vistas de frente y desde arriba |

No están en el repo: los `.blend` (pasan de 100 MB), las texturas y modelos de Poly Haven, las fotos de referencia ni las imágenes de satélite.
